```text
Skills:
Read (root AGENTS.md, nearest package AGENTS.md, canonical sections):
Input / output interfaces:
Acceptance tests:
Benchmarks / hot path / performance constraints:
Determinism impact:
Save / mod impact:
Art / visual impact (skill, sections):
Screen / UI impact (skill, sections):
Verification commands:
Ledger: append a section per .agents/templates/HANDOFF.md
```
